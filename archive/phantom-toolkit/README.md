# Phantom Toolkit

[![](https://img.shields.io/badge/python-3.12+-blue.svg)](https://www.python.org/downloads/)
[![](https://img.shields.io/badge/typescript-5.8-blue.svg)](https://www.typescriptlang.org/)
[![](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![](https://img.shields.io/badge/platform-Windows%20|%20Linux-lightgrey.svg)](#installation)

Phantom Toolkit is a comprehensive open-source utility for **Elden Ring** and **Dark Souls III**. It provides essential tools for build creation, stat editing, and safe-guarding your progress.

---

## Key Features

- **Build Creation & Stat Editing**: Fine-tune your character's stats and equipment for the perfect build.
- **Save Backup & Management**: Automatic and manual backups to ensure you never lose your progress.
- **Cross-Platform Support**: Optimized for both Windows and Linux, including Steam Deck compatibility.
- **Premium GUI**: A modern, atmospheric interface inspired by the artistic style of the games.

---

## Installation

### Windows
1.  Download the latest executable from the [Releases](https://github.com/2Pz/Phantom-Toolkit/releases) page.
2.  Download the [items](https://github.com/2Pz/Phantom-Toolkit/releases/tag/Items) and extract it into the same directory as the executable.
3.  Run `PhantomToolkit.exe`.

### Linux & Steam Deck (AppImage)
1.  Download the latest `.AppImage` from the [Releases](https://github.com/2Pz/Phantom-Toolkit/releases) page.
2.  Make the file executable: `chmod +x PhantomToolkit-x.x.x.AppImage`.
3.  Ensure you have the [items](https://github.com/2Pz/Phantom-Toolkit/releases/tag/Items) folder in the same directory.
4.  **Start the game via Steam (Proton) first**, then run the AppImage.

> **Note:** The game must already be running so the toolkit can automatically find the Proton prefix and attach to the game.

### Running from Source
If you prefer to run from source, follow the instructions in [DEV_README.md](DEV_README.md).
