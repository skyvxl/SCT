# Phantom Toolkit UI

This directory contains the React + Vite UI for Phantom Toolkit.

For overall project setup and build instructions, see the repo root docs:
- `README.md`
- `DEVELOPMENT.md`

## Prerequisites
- Node.js 20+

## Install
From this `gui/` directory:
```bash
npm install
```

## Development server
```bash
npm run dev
```

## Commands
```bash
npm run lint        # ESLint
npm run format      # ESLint --fix
npm run type-check  # TypeScript typecheck (no emit)
npm run build       # Production build
```

Tip: from the repo root you can run `npm run check` to run backend + UI checks together.
